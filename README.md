# ทางสองเรา

เกมสำหรับสองคน มีสิบเจ็ดโหมดให้เลือกจากการ์ดที่หน้าแรก แต่ละการ์ดบอกดาว (หรือหัวใจ) ที่เก็บได้แล้วในโหมดนั้น

ภาพทั้งเกมวาดด้วยโค้ดล้วน ไม่มีไฟล์รูปสักไฟล์ ตัวละครสองตัวมีตาโตเป็นประกาย แก้มแดง โบว์กับต้นอ่อนบนหัว ทุกฉากมีรายละเอียดของตัวเอง ทั้งคนดูบนอัฒจันทร์ โคมกระดาษเหนือเวที ห้องนอนกับผ้าห่มลายหัวใจ บ้านแฟนกับหมาเฝ้าบ้าน ป่าลึกกับลำธารและวิหารโบราณ ส่วนที่ไม่ขยับจะวาดเก็บไว้ครั้งเดียวแล้วประทับลงทุกเฟรม เกมจึงยังลื่นบนมือถือ

เสียงก็สร้างด้วยโค้ดเหมือนกัน ไม่มีไฟล์เสียง ทุกโหมดมีเพลงประกอบของตัวเอง เช่น กล่องดนตรีตอนเฝ้าบ้านกลางคืน เพลงกล่อมจังหวะสามตอนแย่งผ้าห่ม แตรเดินแถวงานกีฬาสี พิณดีดย่องๆ ตอนปีนหน้าต่าง มาริมบาเดินป่าตอนฝ่าดงกับดัก และมาริมบาเนิบๆ ริมหาดตอนติดเกาะ (โหมดดนตรีไม่มีเพลงประกอบเพราะเพลงที่ตีอยู่คือตัวเกม) แต่ละฉากมีเสียงบรรยากาศ เช่น จิ้งหรีด นก แมลงในป่า ลม น้ำ เสียงคนในร้าน แอร์ในห้องนอน และคลื่นกับนกนางนวลบนเกาะ (กลางคืนเป็นจิ้งหรีด) กดพักแล้วเพลงจะเบาและอู้อี้ลง จบด่านมีเสียงดาวเด้งทีละดวง ปิดเพลงแยกจากเสียงเอฟเฟกต์ได้ที่หน้าแรก

**ผจญภัย** ทุกด่านคนเดียวผ่านไม่ได้ ต้องเหยียบหัวกัน ยืนกดเปิดทางให้กัน ช่วยกันเข็นหิน และคิดลำดับให้ดี จนเดินเข้าประตูหัวใจได้พร้อมกันทั้งคู่

- **บทที่ ๑ · ฝึกมือ** 7 ด่าน ด่านละหนึ่งกลไก
- **บทที่ ๒ · ใช้หัว** 6 ด่าน ปริศนาที่ต้องวางแผนลำดับก่อนลงมือ กดพักแล้วขอคำใบ้ได้ด่านละ 3 ข้อ
- **บทที่ ๓ · โลกแปลก** 6 ด่าน กลไกแปลกๆ ที่เปลี่ยนวิธีเล่นทั้งหมด
  - **ด้ายแดง** ผูกสองคนไว้ห่างกันไม่เกิน ๔ ช่อง ใครตกจะห้อยค้าง คนที่ยืนอยู่เดินถอยเพื่อดึงขึ้นมา ด้ายทะลุพื้นและกำแพงได้
  - **ระฆังเงา** แตะแล้วทุกอย่างที่ทำใน ๔ วินาทีจะกลายเป็นเงา เงาเดินตามนั้นแล้วยืนค้าง กดแผ่นได้ และเหยียบหัวได้
  - **หินสลับร่าง** แตะแล้วสองคนสลับที่กันทันที
  - **ถ้ำมืด** มองเห็นแค่รอบตัว
- **บทที่ ๔ · กลไกโบราณ** 6 ด่าน เครื่องจักรเก่าที่ต้องผลัดกันใช้
  - **พัดลม** เป่าลมขึ้นข้างบน ยืนในลมจะลอยขึ้นไป บางตัวทำงานเฉพาะตอนมีคนยืนกดแผ่นเลขเดียวกัน
  - **กระดานหก** คนหนึ่งยืนฝั่งที่ต่ำ อีกคนกระโดดลงฝั่งที่ยกขึ้น คนที่ยืนอยู่จะกระเด็นขึ้นสูงเกินกระโดดเองได้
  - **ประตูมิติ** เดินเข้าฝั่งหนึ่งไปโผล่อีกฝั่ง ลังไม้ที่ดันเข้าไปก็ไปด้วย บางคู่เปิดด้วยสวิตช์โยก
  - **พื้นผุ** พื้นหินสีซีดพังถ้ายืนนานเกินครึ่งวินาที แล้วค่อยกลับมาเหมือนเดิมในไม่กี่วินาที

**ครัววุ่นวาย** เปิดร้านอาหารตามสั่งด้วยกัน หยิบวัตถุดิบ หั่น ทอด ตำ จัดจาน แล้วส่งให้ทันก่อนลูกค้าหมดความอดทน ส่งเร็วได้ทิปเพิ่ม ลูกค้ารอไม่ไหวโดนหัก ฿๑๕ ร้านละ ๒–๓ นาที ได้ดาวตามรายได้ ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดร้านถัดไป

1. **ร้านข้าวไข่เจียว** ร้านแรก ทอดไข่ ตักข้าว ส่ง
2. **กะเพราด่วน** ครัวแบ่งเป็นสองฝั่ง ต้องส่งของข้ามโต๊ะกลางให้กัน ของที่ทิ้งไว้บนเตานานจะไหม้และไฟลุก
3. **ส้มตำปากซอย** มีจานแค่ ๓ ใบ จานสกปรกกลับมาที่ช่องคืนจาน ต้องเอาไปล้างที่อ่างก่อน
4. **ไฟลุก!** เตาร้อนจัด สุกแล้วไหม้ใน ๔ วินาที ไฟลามไปโต๊ะข้างๆ ต้องคอยฉีดถังดับเพลิง
5. **ตลาดน้ำ** ครึ่งครัวอยู่บนเรือที่ลอยขึ้นลง เดินข้ามได้เฉพาะตอนเรือจอดตรงทางเดิน

เมนูในเกม: ข้าวไข่เจียว (ไข่ → กระทะ + ข้าว), ข้าวกะเพราหมู (หมู → หั่น → กระทะ + ข้าว), ส้มตำ (มะละกอ → หั่น → ครก), ต้มยำกุ้ง (กุ้ง → หั่น → หม้อ)

**ป้องกันบ้าน** ผีน้อยบุกมาเคาะบ้านเป็นระลอกทุกคืน ฮีโร่ยิงผีที่ใกล้ที่สุดเอง ผู้เล่นแค่เดินไปยืนให้ดี ใช้ท่าพิเศษ และกดค้างเพื่อช่วยเพื่อน สร้าง หรือซ่อม
- **สายใจ** ยืนห่างกันไม่เกิน ๕ ช่องจะมีเส้นแสงเชื่อมสองคน ผีที่โดนเส้นจะไหม้และเดินช้าลง เส้นนี้ยังกันลูกไฟได้ด้วย
- **ช่วยกันลุก** ใครพลังหมดจะล้ม อีกคนต้องไปยืนข้างๆ แล้วกดใช้ค้างไว้ ๒ วินาที ถ้าล้มทั้งคู่หรือบ้านพังจะแพ้คืนนั้น ยืนใกล้กันพลังจะค่อยๆ ฟื้น
- **ท่าพิเศษ** ชมพูมีระเบิดหัวใจ ผลักผีรอบตัวให้กระเด็น มิ้นต์มีใบไม้ฟื้นใจ รักษาทั้งสองคน ทำให้ผีรอบตัวมึน และพยุงชมพูที่ล้มอยู่ใกล้ๆ ให้ลุกทันที
- **เหรียญ** ผีทิ้งเหรียญไว้ เดินไปใกล้ๆ จะดูดเข้ามาเอง เอาไปสร้างตะเกียงยิงผีบนแท่นหิน (อัปเกรดได้ ๓ ขั้น) หรือซ่อมบ้าน
- ผี ๕ แบบ: ผีน้อยเดินตามทาง กระสือบินเร็วข้ามต้นไม้ ปอบตัวอึดชอบไล่ตีฮีโร่ ผีโขมดลอยห่างๆ แล้วพ่นลูกไฟ และราชาผีที่เรียกผีน้อยมาช่วย

1. **คืนแรกในบ้านใหม่** ผีน้อยมาจากซ้ายกับขวา
2. **กระสือบินว่อน** ทางเข้า ๔ มุม กระสือบินข้ามต้นไม้
3. **ปอบเดินช้า** ปอบกับผีโขมด รั้วฝั่งซ้ายเหลือช่องเดียว
4. **สองบ้านสองใจ** บ้านสองหลัง หลังไหนพังก็แพ้
5. **ราชาผี** คืนสุดท้ายกับบอส

ดาวคิดจากเลือดบ้านที่เหลือตอนฟ้าสาง (ถ้ามีสองหลังนับหลังที่เหลือน้อยกว่า) รอดคืนไหนก็เปิดคืนถัดไป

**ขับรถคู่** ขับรถกระบะส่งของคันเดียวกัน คนหนึ่งคุมพวงมาลัยได้แค่ซ้ายขวา อีกคนคุมคันเร่งกับเบรก (กดเบรกค้างตอนรถหยุดแล้วจะถอยหลัง) รถเลี้ยวได้เฉพาะตอนวิ่ง ต้องบอกกันตลอดว่าจะเลี้ยว จะเร่ง หรือจะจอด
- รับของที่ร้าน (ช่องจอดสีส้ม) แล้วไปส่งที่บ้าน (ช่องจอดสีฟ้า) ต้องจอดนิ่งในช่องแป๊บหนึ่ง บนรถใส่ได้ ๒ ชิ้น ส่งเร็วได้ทิป ชนแรงๆ ของจะบุบ เงินที่ได้ก็ลด
- คนคุมพวงมาลัยมีแตรไล่ไก่ คนคุมคันเร่งมีเทอร์โบ ๓ ครั้ง ส่งของสำเร็จได้คืนครั้งละหนึ่ง สลับหน้าที่กันได้ในเมนูพัก
- มีลูกศรขอบจอกับแผนที่เล็กมุมขวาล่างชี้ร้านและบ้านที่ต้องไป

1. **ซอยบ้านเรา** ถนนโล่งไว้ฝึกมือ
2. **ตลาดเช้า** ไก่เดินตัดหน้า ส่งไข่ไก่ที่แตกง่าย
3. **ถนนใหญ่** รถวิ่งเต็มถนน (ชิดซ้ายแบบเมืองไทย) ส่งเค้ก
4. **ทางรถไฟ** รถไฟวิ่งผ่านเป็นระยะ ไฟแดงกะพริบกับไม้กั้นลงก่อนรถไฟมา ส่งไอติมที่รอได้ไม่นาน
5. **ฝนตกถนนลื่น** รถไถลตอนเลี้ยว แอ่งน้ำลื่นกว่าเดิม มีทุกอย่างรวมกัน

**ตะกร้อลอดห่วง** สองคนช่วยกันเดาะตะกร้อ ส่งลูกให้กันกลางอากาศ แล้วกระโดดเตะลงห่วงที่แขวนอยู่กลางลาน
- ยืนบนพื้นแล้วเตะพร้อมกดทิศไปหาเพื่อน ลูกจะโค้งไปตกตรงหัวเพื่อนพอดี ถ้าไม่กดทิศจะเดาะขึ้นเหนือหัวตัวเอง
- กระโดดแล้วเตะเป็นลูกยิงเข้าห่วง ลูกที่เพื่อนส่งมาให้ยิงแม่นกว่าลูกที่เดาะเอง หันหลังให้ห่วงแล้วยิงเป็นลูกส้นหลัง ได้แต้มสองเท่า
- ลูกจะได้แต้มต้องผ่านเท้าเพื่อนก่อนอย่างน้อยหนึ่งทอด ส่งกันไปมาก่อนยิงแต้มจะคูณเพิ่มทีละครึ่ง สูงสุดสามเท่า ลูกตกพื้นต้องเริ่มนับใหม่
- เล่นเครื่องเดียว ลูกที่ตกใส่หัวคนที่กำลังกระโดดจะเด้งเป็นลูกโหม่ง เล่นออนไลน์ต้องกดเตะเอง เพราะสองเครื่องเห็นตัวละครช้ากว่ากันนิดหนึ่ง

1. **ลานวัด** ห่วงเดียวกลางลาน ไว้ฝึกส่งแล้วยิง
2. **ใต้ต้นมะขาม** กิ่งไม้ยื่นมาบังทางลูก ลูกโดนกิ่งจะเด้งออก
3. **ห่วงแกว่ง** ห่วงแกว่งไปมา ลูกยิงเล็งตามให้ แต่ยิ่งไกลห่วงยิ่งพลาดง่าย
4. **ลมทะเล** ลมพัดลูกเป็นช่วงๆ ดูธงบนเสา ลูกยิงเผื่อลมให้แค่ครึ่งเดียว
5. **งานวัดกลางคืน** สองห่วง ไฟติดทีละห่วงแล้วสลับทุกสิบวินาที ลูกที่ลอดห่วงไฟดับไม่ได้แต้ม

ได้ดาวตามแต้มที่ทำได้ในเวลา ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดสนามถัดไป

**ดนตรีจังหวะคู่** วงดนตรีสองคน ชมพูตีกลองยาว มิ้นต์ตีระนาด (เพลงที่ ๔ เป็นโปงลาง) โน้ตตกลงมาตามเลนของแต่ละคน ตีให้ตรงตอนโน้ตถึงวงกลม ทุกเพลงแต่งขึ้นใหม่สำหรับเกมนี้
- แต่ละคนมีสองเลน เสียงต่ำกับเสียงสูง ตีตรงเป๊ะ (ไม่เกิน ๔๕ มิลลิวินาที) ได้ **เป๊ะ** รองลงมาเป็น **ดี** กับ **พอได้** ตีเร็วเกินไปมากจะเสียโน้ตตัวนั้นไปเลย กดรัวมั่วๆ จึงไม่ช่วย
- คอมโบกับ **พลังวง** ใช้ร่วมกัน ใครพลาดคอมโบของวงก็หลุดทั้งคู่ คอมโบ ๑๐ ขึ้นไปแต้มคูณครึ่ง ๒๕ ขึ้นไปคูณสอง พลังวงหมดเมื่อไหร่วงล่มกลางเพลง
- โน้ตของสองคนที่มาพร้อมกัน (มีเส้นทองโยง) เป็น **คอร์ด** ตีพร้อมกันห่างไม่เกิน ๔๐ มิลลิวินาทีได้โบนัส ติดกันสี่คอร์ดวงจะ **เข้าขา** แต้มสองเท่าไปสิบหกจังหวะ
- มีเสียงฉิ่งฉับกับเบสเป็นจังหวะให้ตลอดเพลง และนับ ๔ จังหวะก่อนเริ่ม เปิดเสียงด้วยจะเล่นง่ายขึ้นมาก

1. **ฝึกตีคู่ที่ลานบ้าน** ช้าๆ ผลัดกันตีแล้วค่อยตีพร้อมกัน
2. **กลองยาวแห่ขบวน** กลองนำหนึ่งห้อง ระนาดตอบหนึ่งห้อง
3. **ระนาดริมน้ำ** ระนาดไล่ทำนองยาว และท่อนตีสลับกันคนละครึ่งจังหวะ
4. **โปงลางอีสาน** เร็วขึ้นเป็นครึ่งจังหวะ ท่อนเรียกตอบเร็ว
5. **เวทีงานวัด** เพลงปิดงาน เร็วและแน่น ท่อนคอร์ดรัวยาว

ได้ดาวตามความแม่น (เพลงแรก ๕๕ ๗๕ และ ๘๘ เปอร์เซ็นต์ เพลงอื่น ๖๐ ๗๘ และ ๙๐) และต้องเล่นจบเพลงโดยพลังวงไม่หมด ถึงจะเปิดเพลงถัดไป

**ต่อตึกด้วยกัน** ตึกแต่ละชั้นมีสองครึ่ง ครึ่งซ้ายของชมพู ครึ่งขวาของมิ้นต์ แต่ละคนมีปั้นจั่นของตัวเองที่แกว่งครึ่งตึกไปมา กดปุ่มเดียวเพื่อปล่อย
- ส่วนที่ยื่นเกินครึ่งของตัวเองในชั้นล่างจะโดนตัดทิ้ง ครึ่งตึกจึงแคบลงเรื่อยๆ ลงห่างจุดพอดีไม่เกิน ๕ พิกเซลจะ **เป๊ะ** ไม่โดนตัด และงอกกลับนิดหนึ่ง โดยงอกเข้าหาครึ่งของเพื่อนก่อน
- ชั้นที่สองครึ่งชนกันพอดีเป็น **ต่อสนิท** ทำให้ตึกนิ่งลง ถ้ารอยต่อห่าง ตึกจะโยกมากขึ้น ชั้นต่อๆ ไปก็ยากขึ้นสำหรับทั้งคู่
- มี **หมวกนิรภัย** ๓ ใบใช้ร่วมกัน ครึ่งตึกที่ตกไม่โดนชั้นของตัวเองเลยเสียหนึ่งใบ ลงเป๊ะทั้งคู่ในชั้นเดียวกันได้คืนหนึ่งใบ หมวกหมดเมื่อไหร่ปิดไซต์
- ปั้นจั่นรอได้ประมาณห้าวินาที ถ้ายังไม่กดจะปล่อยเอง มีวงนับถอยหลังที่ตะขอ

1. **บ้านไม้หลังแรก** ๑๒ ชั้น ปั้นจั่นแกว่งช้า
2. **ตึกแถวในเมือง** ๑๖ ชั้น ปั้นจั่นสองตัวเร็วไม่เท่ากัน และสลับกันทุกสี่ชั้น
3. **ทุ่งลมแรง** ๑๖ ชั้น ลมพัดครึ่งตึกที่กำลังตกให้ลอยไปด้านข้าง ดูธงที่ปลายปั้นจั่น ลมเปลี่ยนทุกสามชั้น
4. **คอนโดริมทะเล** ๒๐ ชั้น ยิ่งสูงตึกยิ่งโยก ต้องปล่อยให้ตกถึงตอนตึกโยกกลับมาพอดี
5. **เจดีย์บนดอย** ๒๒ ชั้น ครึ่งตึกสอบแคบลงเองทุกชั้น มีลมกับโยกนิดๆ

ได้ดาวตามจำนวนชั้นที่ต่อได้ ดาวที่สามคือต่อจนถึงยอด ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดไซต์ถัดไป

**วิ่งสามขา** วิ่งสามขางานกีฬาสี ขาในของสองคนผูกติดกัน แต่ละคนมีปุ่มขาในกับขานอก
- กดขาในพร้อมกัน แล้วขานอกพร้อมกัน สลับไปเรื่อยๆ ใน นอก ใน นอก กดห่างกันไม่เกิน ๖๐ มิลลิวินาทีเป็นก้าว **เป๊ะ** ก้าวยาวสุด ไม่เกิน ๑๕๐ เป็นก้าว **ดี** ห่างกว่านั้นก้าวสั้นและเสียหลักนิดหนึ่ง
- **หลัก** ใช้ร่วมกัน กดผิดขา กดคนละขา (ขาพันกัน) หรือรีบกดเร็วเกินจังหวะจะเสียหลัก ใครกดแล้วอีกคนไม่ตาม จะยืนขาเดียวโยกเยก หลักหมดเมื่อไหร่ล้มทั้งคู่ ต้องรอลุกเกือบสองวินาที
- แข่งกับอีกสามทีม ทีมเขียว ทีมเหลือง และทีมแดงแชมป์เก่า กดรัวมั่วๆ จะล้มบ่อยจนไม่ถึงเส้นชัย

1. **ลานโรงเรียน** ทางเรียบไว้หาจังหวะ
2. **สนามหญ้าหลังฝนตก** แอ่งโคลนทำให้ก้าวสั้นลง พลาดในโคลนเสียหลักมากกว่าปกติ
3. **วิ่งข้ามรั้ว** รั้วเตี้ยสี่รั้ว ถึงรั้วแล้วต้องหยุด ก้าวต่อไปต้องกดห่างกันไม่เกิน ๑๑๐ มิลลิวินาทีถึงจะกระโดดข้าม ไม่งั้นสะดุดล้ม
4. **เนินหลังโรงเรียน** ขึ้นเนินก้าวสั้นต้องกดถี่ ลงเนินก้าวยาวแต่กดเร็วเกินจะสะดุด
5. **รอบชิงงานกีฬาสี** มีครบทุกอย่าง บนพื้นเปียกกดผิดขาหรือคนละขาจะล้มทันที

ได้ดาวตามจำนวนทีมที่วิ่งชนะ ชนะทีมแดงได้สามดาว ต้องชนะอย่างน้อยหนึ่งทีมถึงจะเปิดสนามถัดไป

**เรือยาวพายคู่** สองคนนั่งเรือลำเดียว ชมพูพายฝั่งซ้าย มิ้นต์พายฝั่งขวา แต่ละคนมีปุ่มพายกับปุ่มทวน
- พายข้างเดียวเรือจะเลี้ยวไปอีกฝั่ง อยากเลี้ยวขวาให้ชมพูพาย อยากเลี้ยวซ้ายให้มิ้นต์พาย ทวนน้ำเป็นเบรกและหมุนเรือเร็วขึ้น
- พายพร้อมกันห่างไม่เกิน ๑๒๐ มิลลิวินาทีเป็น **พายพร้อม** เรือพุ่งแรงขึ้นและไม่ส่าย พายแต่ละครั้งใช้เวลาเกือบครึ่งวินาที กดซ้ำก่อนพายจบไม่มีผล กดรัวจึงไม่ช่วย
- น้ำไหลสวนมาตลอด ชนตลิ่ง หิน เรือแม่ค้า หรือขอนไม้แรงๆ เรือจะร้าว ร้าวจนหมดเรือล่ม ชนเบาๆ แค่กระเด้ง
- เก็บกระทงได้ลดเวลาชิ้นละหนึ่งวินาที

1. **คลองหน้าบ้าน** คลองคดเคี้ยวไว้ฝึกพายพร้อมกันกับเลี้ยว
2. **ตลาดน้ำ** เรือแม่ค้าพายตัดหน้าไปมา
3. **แก่งหินเชี่ยว** น้ำเชี่ยวผลักเรือไปด้านข้าง หินเต็มแก่ง
4. **แข่งเรือยาวประเพณี** แข่งกับเรืออีกสามลำ ทางยาวแต่โล่ง
5. **คืนลอยกระทง** กลางคืนมีกระทงเต็มแม่น้ำ ขอนไม้ลอยมา และวังน้ำวนหมุนเรือ

ได้ดาวตามเวลาถึงเส้นชัยหลังหักกระทง ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดสายน้ำถัดไป

**ย้ายบ้านแบกของ** รับจ้างย้ายบ้าน ขนของจากรถกระบะเข้าไปจัดในบ้าน มองจากด้านบน
- โซฟา เตียง โต๊ะ ตู้ ตู้เย็น กระจก เปียโน และศาลพระภูมิ ต้องยกสองคน ไปยืนคนละปลายแล้วกดยกทั้งคู่ ถือปลายเดียวยกไม่ขึ้น
- ยกแล้วของเป็นชิ้นเดียวกัน เดินไปทางเดียวกันของไปตรงๆ เดินสวนกันของจะหมุน ชนกำแพงของจะไถลไปตามหรือหมุนรอบปลายที่ติด ต้องหันของให้ตรงกับประตูก่อนดันเข้า
- วางให้ตรงเส้นประ หันถูกทางแล้วเส้นประจะเป็นสีเขียว ศาลพระภูมิหันได้ทางเดียวตามลูกศร ของชิ้นเล็ก (กล่อง ทีวี ต้นไม้) ถือคนเดียวได้ วางที่ไหนก็ได้ในห้องที่เขียนไว้
- ชนแรงๆ ของจะบุบ ของบอบบางอย่างกระจกกับทีวีบุบง่ายกว่า บุบแล้วได้เงินน้อยลง ย้ายครบก่อนหมดเวลาได้ทิปวินาทีละ ๓ บาท

1. **ห้องเช่าห้องแรก** โซฟากับโต๊ะ ทางเข้ากว้าง
2. **บ้านเดี่ยวทางเลี้ยว** ทางไปห้องนอนหักศอก ตู้ยาวต้องค่อยๆ หมุนผ่านมุม
3. **ทาวน์เฮาส์ประตูแคบ** ประตูห้องข้างในกว้างช่องเดียว กระจกบานใหญ่แตกง่าย
4. **ฝนตกต้องรีบ** ของที่วางอยู่ข้างนอกเกินสิบวินาทีจะเปียกแล้วค่อยๆ เสียหาย
5. **เปียโนกับศาลพระภูมิ** เปียโนหนักเดินช้า ศาลพระภูมิต้องหันหน้าให้ถูก

ได้ดาวตามเงินที่ได้ ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดบ้านหลังถัดไป

**ชักว่าวคู่** คนหนึ่งเป็นคนวิ่ง อีกคนเป็นคนคุมสาย (สลับหน้าที่ได้ในเมนูพัก) ลมพัดไปทางขวา ว่าวลอยอยู่ด้านใต้ลมของคนวิ่ง
- ใกล้พื้นลมเบา ว่าวขึ้นเองไม่ได้ คนวิ่งต้องวิ่งสวนลมไปทางซ้าย ส่วนคนคุมสายผ่อนสายตอนว่าวกินลม พอว่าวขึ้นไปสูงพอ ลมข้างบนจะพยุงไว้เอง
- **ผ่อนสาย** สายจะไหลออกเฉพาะตอนว่าวดึงมือ ว่าวยิ่งดึงแรงสายยิ่งไหลเร็ว สายยาวขึ้นแล้วว่าวจะลอยสูงขึ้น **ดึงสาย** ทำให้ว่าวกินลมมากขึ้นแต่สายตึงขึ้นด้วย **กระตุก** ช่วยเชิดหัวว่าวตอนกำลังร่วง คนวิ่งมี **วิ่งเร็ว** ไว้ส่งว่าวกับตอนลมหยุด
- **สายตึง** ขึ้นที่มุมขวาบน ตึงเกินไปนานเกือบครึ่งวินาทีสายจะขาด ลมกระโชกจะมีคำเตือนกับธงสะบัดก่อน ต้องผ่อนสายไว้ ถ้าสายหมดม้วนจะผ่อนไม่ได้แล้ว สายสั้นๆ ตอนเพิ่งส่งว่าวไม่ขาดง่าย
- ว่าวร่วงลงพื้น ติดต้นไม้ ติดสายไฟ สายขาด หรือโดนสายคนอื่นเสียดจนขาด จะได้ว่าวตัวใหม่กลับมาที่มือบนสายสั้นๆ ในอีกสองวินาที
- แต้มคือความสูงของว่าว (เมตร เหนือ ๘ เมตรแรก) ทุกวินาทีที่อยู่บนฟ้า มีป้ายบอกใบ้ว่าตอนนี้ใครควรทำอะไรอยู่เหนือหัวทั้งสองคน

1. **ทุ่งนาหลังเก็บเกี่ยว** ลมนิ่ง ไว้ฝึกส่งว่าวกับผ่อนสาย
2. **ลมว่าวเดือนมีนา** ลมกระโชกเป็นพักๆ
3. **ริมคลองหลังวัด** ต้นไม้กับสายไฟข้างหน้า ลมหยุดเป็นช่วงๆ สนามแคบเพราะมีคลอง
4. **สนามหลวงงานว่าว** ว่าวคนอื่นเต็มฟ้า สายว่าวจุฬาที่ยาวพาดเหนือสนามเป็นเพดาน ต้องให้ว่าวเราอยู่ใต้สายเขา
5. **แข่งว่าวจุฬาปักเป้า** ครบทุกอย่าง ลมกระโชก ลมหยุด ต้นไม้ และคนชักว่าวที่เดินไปมา

ได้ดาวตามแต้ม ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดลานถัดไป

**แอบจุ๊บในโรงหนัง** ชมพูนั่งซ้าย มิ้นต์นั่งขวา แต่ละคนกดค้างเพื่อเอียงเข้าหากัน เอียงสุดพร้อมกันคือจุ๊บ แต้มไหลเข้าเรื่อยๆ จุ๊บนานถึง ๒ วินาทีแต้มคูณ ๑.๕ ถึง ๔ วินาทีคูณ ๒
- คนรอบๆ ชอบหันมามอง ก่อนมองทุกคนจะมีสัญญาณก่อนเสมอ (หัวเริ่มหัน มือถือยกขึ้น พนักงานเดินถือไฟฉายมา) คนฝั่งซ้ายเป็นหน้าที่ชมพูคอยดู ฝั่งขวาเป็นของมิ้นต์ ถ้ามีคนมองตอนที่ยังเอียงอยู่จะโดนเห็น หักแต้ม และต้องนั่งหน้าแดงแป๊บหนึ่ง โดนเห็นครบสามครั้งพนักงานเชิญออกจากโรง (แต้มที่ได้แล้วยังอยู่)
- แต่ละคนยกถังป๊อปคอร์นบังฝั่งตัวเองได้ ๒ วินาทีกว่าๆ แล้วต้องรออีก ๑๒ วินาที ฉากสว่างเอียงนิดเดียวก็เห็น ฉากเสียงดังไม่มีใครหันมา ฉากผีออกทุกคนสะดุ้งดูจอ กอดกันตอนนั้นได้โบนัส

1. **รอบบ่ายวันธรรมดา** ป้าแถวหน้าคนเดียว ไว้ฝึกจังหวะ
2. **หนังผีรอบดึก** ผีออกสี่ครั้ง กับเด็กข้างๆ ที่ชอบหันมาดู
3. **หนังบู้ฟอร์มยักษ์** ฉากระเบิดเสียงดังให้จุ๊บได้นาน แต่ระเบิดทำให้ห้องสว่าง และมีพนักงานถือไฟฉาย
4. **รอบปฐมทัศน์คนแน่นโรง** ป้า ผู้ชายข้างหลัง คนถ่ายรูปเปิดแฟลช และพนักงาน ต้องแบ่งกันดูดีๆ
5. **หนังกลางแปลงงานวัด** ครบทุกอย่าง ผีออกสามครั้ง ฉากเปลี่ยนเร็ว

ได้ดาวตามแต้ม ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดรอบถัดไป

**เดทแรกห้ามตด** คนหนึ่งท้องปั่นป่วน อีกคนช่วยกลบเสียง (สลับหน้าที่ได้ในเมนูพัก)
- แก๊สขึ้นเรื่อยๆ (กินของบางอย่างแล้วขึ้นเร็ว) คนท้องปั่นป่วนกดค้างเพื่อเกร็ง แก๊สจะขึ้นช้าลงแต่หน้าแดงขึ้นเรื่อยๆ เกร็งนานเกินไปหรือแก๊สเต็มจะหลุดออกมาเอง
- กดปล่อยแล้วเสียงจะดังตามมาครึ่งวินาที ดังเท่าแก๊สที่สะสมไว้ อีกคนต้องไอ (กลบตัวเล็กถึงกลาง) หรือลากเก้าอี้ (กลบได้ทุกขนาด แต่ใช้ได้ทุก ๕ วินาที) ให้เสียงไปตรงกับตอนที่ตด ตอนร้านเสียงดังอยู่แล้ว (จานแตก เพลง โต๊ะข้างๆ หัวเราะ เด็กร้อง ฟ้าร้อง ปรบมือ) ปล่อยได้เลยและได้แต้มเพิ่ม
- ตดเนียนได้แต้ม ยิ่งใหญ่ยิ่งได้มาก มีคนได้ยินเป็นหนึ่งครั้งที่โดนจับได้ ไอหรือลากเก้าอี้โดยไม่มีอะไรให้กลบบ่อยๆ คนจะเริ่มสงสัย ตัวใหญ่ที่ปล่อยตอนพัดลมหันไปหาโต๊ะอื่นจะมีคนได้กลิ่น โดนจับได้ครบสามครั้งมื้อนั้นพัง

1. **เดทแรกร้านกาแฟ** ร้านเงียบๆ ยอมให้พลาดได้ห้าครั้ง
2. **ร้านหมูกระทะ** ร้านเสียงดังกลบง่าย แต่ท้องปั่นป่วนเร็วและมีพัดลมส่าย
3. **ติวหนังสือในห้องสมุด** เงียบกริบ มีแค่ฟ้าร้องนานๆ ครั้ง
4. **กินข้าวกับพ่อแม่แฟน** พัดลมกับเด็กข้างโต๊ะ ไอบ่อยก็ดูแปลก
5. **งานแต่งเพื่อนสนิท** เพลง ปรบมือ และจานแตกเป็นระยะ แต่อยู่ทั้งงาน

ได้ดาวตามแต้ม ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดมื้อถัดไป

**แย่งผ้าห่ม** นอนสองคนผ้าห่มผืนเดียวในห้องแอร์ มองจากบนเพดาน แต่ละคนขยับตัวเองบนเตียงและกดค้างเพื่อดึงผ้าห่มเข้าหาตัว
- อยู่ใต้ผ้าห่มจะอุ่นขึ้นจนสบาย หลุดจากผ้าห่มจะหนาวลงเรื่อยๆ (แอร์ยิ่งเย็นยิ่งเร็ว) นอนชิดกันอุ่นกว่า ร้อนเกินไปก็นอนไม่หลับ ไม่สบายตัวนานๆ จะตื่น ตื่นครบสามครั้งคืนนั้นพัง
- ดึงพร้อมกันคนละทางคือแย่งผ้าห่ม ไม่มีใครได้และตื่นง่าย ตอนหลับตัวจะไหลไปเองช้าๆ แต่ละคนต้องคอยไม่ให้ตัวเองตกเตียง
- กลางดึกมีคนดิ้นเตะผ้าห่ม กลิ้งหนีพาผ้าห่มไปด้วย ร้อนวูบ ตดใต้ผ้าห่ม (กดปุ่มตบเพื่อสะบัดผ้าไล่กลิ่น แต่ลมเย็นจะเข้า) และยุงมากัด (ตบตอนยุงเกาะ ตบตัวเองสะดุ้งนิดเดียว ตบให้แฟนแฟนสะดุ้งมากกว่า) ทุกอย่างมีสัญญาณก่อน
- แต้มขึ้นทุกวินาทีที่ทั้งคู่หลับ ยิ่งสบายและห่มมิดยิ่งได้มาก นอนชิดกันได้เพิ่ม

1. **คืนแรกในห้องใหม่** ยอมให้ตื่นได้สี่ครั้ง ไว้ฝึก
2. **แอร์เย็นเฉียบ** ผ้าห่มเล็กลงและมีช่วงแอร์เย็นจัด
3. **ยุงบุกห้อง** ยุงมาหลายตัว
4. **หลังกินหมูกระทะ** ตดใต้ผ้าห่มบ่อย
5. **คืนก่อนวันแต่งงาน** ตื่นเต้นจนดิ้นทั้งคืน มีทุกอย่าง

ได้ดาวตามแต้ม ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดคืนถัดไป

**ปีนหน้าต่างหาแฟน** แอบไปหาแฟนกลางดึก คนหนึ่งเป็นคนปีน อีกคนรออยู่บนห้อง (สลับหน้าที่ได้ในเมนูพัก) มองบ้านจากด้านหน้า
- คนปีนเดินจากประตูรั้วไปใต้หน้าต่างห้องแฟน พ่อเดินไปห้องไหนไฟห้องนั้นจะเปิด (มีแสงเรืองๆ ก่อนไฟเปิด) ขยับในที่สว่างจะโดนเห็น แต่ยืนนิ่งๆ ไม่มีใครสังเกต รถที่ผ่านมามีเสียงเครื่องก่อน แล้วไฟหน้ารถจะส่องไปทั่วหน้าบ้าน ทางกรวดเดินเร็วแล้วเสียงดัง หมาจะตื่นแล้วเห่า พ่อจะมาส่องไฟฉายที่หน้าต่าง ตอนนั้นยืนนิ่งก็เห็น ต้องซ่อนในพุ่มไม้หรือหนีให้พ้นไฟ
- คนบนห้องหย่อนผ้าปูที่นอนลงมาให้ปลายอยู่ในระยะที่จับได้ ดึงเก็บตอนรถมา (ผ้าที่ห้อยอยู่โดนไฟรถส่องจะมีคนเห็น) และช่วยดึงตอนคนปีนอยู่บนผ้า ได้ยินพ่อเดินขึ้นบันไดต้องรีบขึ้นเตียงแกล้งหลับก่อนพ่อเปิดประตู ระหว่างนั้นไม่มีใครจับผ้า คนปีนปีนต่อไม่ได้และจะไหลลงช้าๆ
- แรงเกาะหมดกลางทางจะร่วง ร่วงจากที่สูงนับเป็นโดนจับได้ด้วย โดนจับได้ครบสามครั้งหรือฟ้าสางก่อนเข้าห้องได้คือไม่สำเร็จ เข้าห้องได้เร็วได้แต้มมาก โดนจับได้แต่ละครั้งหักหนัก

1. **คืนแรกที่แอบมา** ไม่มีหมา ไว้ฝึก
2. **ทางกรวดกับหมาเฝ้าบ้าน** ทางกรวดสองช่วงกับหมาที่ตื่นง่าย
3. **พ่อเดินตรวจบ้าน** ไฟเปิดปิดตลอด และพ่อแวะเปิดประตูห้องแฟนบ่อย
4. **ห้องชั้นสาม** ห้องสูงขึ้น ต้องผูกผ้าปูสองผืน ปีนนานจนแขนล้า
5. **เซอร์ไพรส์วันเกิด** ถือเค้กปีนขึ้นไป ปีนช้าลง และมีทุกอย่าง

ได้ดาวตามแต้ม เข้าห้องได้โดยไม่โดนจับเลยได้อย่างน้อยสองดาว ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดภารกิจถัดไป

**ฝ่าดงกับดัก** ผจญภัยฝ่าป่าลึกไปหาวิหารโบราณ มองจากด้านบน เดินไปได้ทุกทางตามจังหวะของตัวเอง เส้นทางยาวและจอเลื่อนตามสองคน (ห่างกันเกินจอไม่ได้)
- กับดักมีหลายแบบ หนามโผล่จากพื้นเป็นจังหวะ (โผล่ปลายให้เห็นก่อนทุกครั้ง) หน้ากากบนกำแพงยิงลูกธนู ท่อนไม้กับหินกลิ้งลงมาจากช่องในป่า คานไฟหมุนรอบเสาหิน ใบเลื่อยวิ่งตามราง และลำธารที่ต้องเหยียบหินข้าม
- แผ่นหินทำงานเฉพาะตอนมีคนยืนอยู่ เปิดประตู หยุดหนาม ดับไฟ หรือหยุดใบเลื่อย คนหนึ่งยืนค้างให้อีกคนผ่าน แล้วอีกคนไปยืนแผ่นหินฝั่งโน้นให้คนแรกตามมา แผ่นหินกับสิ่งที่มันคุมมีสีเดียวกัน คันโยกคู่ต้องดึงพร้อมกัน (ห่างกันไม่ถึงวินาที) ประตูถึงจะเปิดค้าง
- ใครโดนกับดักจะล้มอยู่ตรงนั้น อีกคนต้องเดินไปยืนข้างๆ ครู่หนึ่งเพื่อช่วยพยุง ล้มอยู่คนเดียวนานเกิน ๑๐ วินาที หรือล้มพร้อมกันทั้งคู่ เสียหัวใจหนึ่งดวงแล้วกลับไปเริ่มที่จุดเซฟล่าสุด (แถวหินที่จุดไฟไว้) หัวใจหมดคือไม่สำเร็จ เก็บหัวใจเพิ่มได้ระหว่างทาง
- ถึงประตูวิหารพร้อมกันทั้งคู่คือผ่าน แต้มมาจากการไปถึง เพชรที่เก็บได้ หัวใจที่เหลือ และเวลาที่เหลือ ล้มแต่ละครั้งหักนิดหน่อย

1. **ทางเข้าป่า** หนามเป็นจังหวะ ประตูแผ่นหิน ท่อนไม้กลิ้ง และคันโยกคู่แรก ไว้ฝึก
2. **ลำธารหินลื่น** เหยียบหินข้ามลำธารหลายสาย ห้องที่หน้ากากยิงธนู
3. **ถ้ำไฟ** คานไฟหมุน ทางแยกสองเลนที่ต้องกดหยุดกับดักให้กัน และหนามเป็นคลื่น
4. **วิหารใบเลื่อย** ใบเลื่อยวิ่งตามราง ยาวขึ้นและมีจุดเซฟเป็นระยะ
5. **ทางกลับบ้าน** ยาวที่สุด กับดักทุกแบบมารวมกัน

ได้ดาวตามแต้ม ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดเส้นทางถัดไป

**ติดเกาะกับแฟน** เรือล่ม สองคนติดเกาะร้างกลางทะเล ต้องอยู่ให้รอดสามวันสามคืน (เกาะละราว ๙ นาที) มองจากด้านบน เกาะทั้งเกาะอยู่ในจอเดียว
- แต่ละคนมีแถบหิว น้ำ และความอุ่น หมดแถบไหนก็หมดแรงล้มอยู่ตรงนั้น อีกคนต้องไปยืนข้างๆ ครู่หนึ่งเพื่อช่วยให้ฟื้น ปล่อยไว้นานเกินหรือหมดแรงพร้อมกันทั้งคู่ เสียหัวใจหนึ่งดวงแล้วเริ่มวันนั้นใหม่
- ปุ่มเดียวทำได้ทุกอย่างตามที่อยู่ตรงหน้า เขย่าต้นมะพร้าว (ลูกหล่นตรงเงาที่ใหญ่ขึ้น กดรับตอนหล่นถึงพื้น ไม่งั้นโป๊กหัว) เก็บกล้วย ดื่มน้ำจากตาน้ำในป่า (น้ำทะเลเค็ม) ตะครุบปลาในแอ่ง (คนหนึ่งไล่ปลา อีกคนรอตะครุบ ปลาดิบต้องย่างก่อน ไม่งั้นท้องเสีย ปู้ด) เก็บฟืน ถูไม้ก่อไฟต้องผลัดกันกดคนละที กดซ้ำคนเดิมควันโขมง และยื่นของให้แฟน
- กลางคืนหนาว ต้องนั่งข้างกองไฟที่ติดอยู่ ไฟกินฟืนตลอด ฝนตกไฟมอดเร็ว นั่งข้างกองไฟด้วยกันตอนกลางคืนความรักเพิ่มขึ้นเรื่อยๆ
- แถบความรักตรงกลางจอลดลงช้าๆ และลดฮวบเมื่อเขย่ามะพร้าวใส่หัวแฟน กินคนเดียวตอนแฟนหิวกว่า ปล่อยไฟดับตอนกลางคืน ต่ำกว่าเส้นเมื่อไหร่ฝ่ายที่โดนจะงอน (หันหลัง มีเมฆฝนบนหัว) ต้องเอาดอกไม้หรือของกินไปง้อ ความรักหมดคือทะเลาะจนต้องเริ่มวันใหม่ ให้ดอกไม้กันเฉยๆ ก็ได้ความรักเพิ่ม
- สัตว์ป่วนเกาะ ปูเดินบนหาด เดินชนโดนหนีบก้นวิ่งร้องลั่นและของหลุดมือ ลิงออกจากป่ามาขโมยของที่วางไว้ (ชอบของกินที่สุด) และหยิบหินออกจาก SOS ลิงที่ถือของวิ่งช้าไล่จับได้ น้ำขึ้นท่วมหาดเปียกเป็นพักๆ เดินช้า ตัวเปียก และพาของบนหาดไป
- วันสุดท้ายเรือจะผ่านสองรอบ ต้องเรียงหินเป็น S O S บนหาดให้ครบ และจุดไฟให้ควันขึ้นตอนเรือผ่าน เรือถึงจะเห็น ถ้าพลาดทั้งสองลำเสียหัวใจแล้วเริ่มวันสุดท้ายใหม่

1. **เกาะแรกพบ** ไม่มีสัตว์ป่วน ฝนไม่ตก ไว้ฝึก
2. **หาดปูหนีบ** ปูสามตัว กล้วยกับมะพร้าวงอกช้า ต้องจับปลา
3. **เกาะลิงซน** ลิงขโมยของกับหินจาก SOS ฝนตกช่วงกลางวัน
4. **น้ำขึ้นน้ำลง** น้ำขึ้นท่วมหาดทุกวัน ทั้งปูและลิง
5. **คืนพายุ** หิวเร็ว คืนหนาวจัด ฝนตกบ่อย SOS ใช้หินมากขึ้น ทุกอย่างมารวมกัน

รอดแล้วได้แต้มตามความรัก หัวใจที่เหลือ ความอิ่ม ความอุ่นตอนจบ และขึ้นเรือลำแรกได้ก็มีโบนัส หมดแรง โดนมะพร้าว โดนปูหนีบ ถูไม้จนควันขึ้น หรือกินคนเดียว หักนิดหน่อย ต้องได้อย่างน้อย ๑ ดาวถึงจะเปิดเกาะถัดไป

ไม่ต้องติดตั้งอะไร เปิดในเบราว์เซอร์ได้เลย ทั้งบนคอมและมือถือ

## วิธีเล่น

โหมดที่ใช้จอยสติ๊กบนมือถือ (ครัววุ่นวาย ป้องกันบ้าน ขับรถคู่ ตะกร้อ ย้ายบ้าน ชักว่าว แย่งผ้าห่ม ปีนหน้าต่าง ฝ่าดงกับดัก ติดเกาะ) จอยลอยได้แบบเกมมือถือ แตะตรงไหนก็ได้ในครึ่งจอฝั่งตัวเอง (เล่นออนไลน์แตะได้ทั้งจอ) จอยจะมาอยู่ใต้นิ้วทันที ลากเลยขอบไปไกลจอยก็ตามนิ้วไป ปล่อยนิ้วแล้วจอยกลับไปที่มุม ปุ่มอยู่ที่เดิม

**สองคนเครื่องเดียว · ผจญภัย**
- คีย์บอร์ด: ตัวชมพูใช้ `W` `A` `D` ตัวมิ้นต์ใช้ปุ่มลูกศร · `R` เริ่มด่านใหม่ · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: หมุนเป็นแนวนอน ปุ่มฝั่งซ้ายของจอเป็นของตัวชมพู ฝั่งขวาเป็นของตัวมิ้นต์

**สองคนเครื่องเดียว · ครัววุ่นวาย**
- คีย์บอร์ด: ตัวชมพูเดินด้วย `W` `A` `S` `D` หยิบ/วางด้วย `Space` ใช้ด้วย `Shift` ซ้าย · ตัวมิ้นต์เดินด้วยปุ่มลูกศร หยิบ/วางด้วย `Enter` ใช้ด้วย `Shift` ขวา · `Esc` พักเกม
- "ใช้" คือกดค้างเพื่อหั่นบนเขียง ตำในครก ล้างจานที่อ่าง หรือฉีดถังดับเพลิง
- มือถือหรือแท็บเล็ต: แต่ละฝั่งของจอมีจอยสติ๊กกับปุ่ม **หยิบ/วาง** และ **ใช้**

**สองคนเครื่องเดียว · ขับรถคู่**
- ตัวชมพูใช้ `W` `A` `S` `D` กับ `Space` ตัวมิ้นต์ใช้ปุ่มลูกศรกับ `Enter` ถ้าได้คุมพวงมาลัยจะใช้แค่ซ้ายขวา ถ้าได้คุมคันเร่งจะใช้แค่ขึ้นลง ปุ่ม `Space` หรือ `Enter` เป็นแตรหรือเทอร์โบตามหน้าที่
- มือถือหรือแท็บเล็ต: คนคุมพวงมาลัยโยกจอยซ้ายขวา คนคุมคันเร่งดันจอยขึ้นเพื่อเร่ง ดึงลงเพื่อเบรกหรือถอย

**สองคนเครื่องเดียว · ป้องกันบ้าน**
- ปุ่มเดียวกับครัววุ่นวาย ปุ่มหยิบ/วางกลายเป็น **ท่าพิเศษ** (ชมพู `Space` มิ้นต์ `Enter`) ส่วนปุ่ม **ใช้** (`Shift` ซ้ายและขวา) กดค้างไว้เพื่อพยุงเพื่อน สร้างหรืออัปเกรดตะเกียง และซ่อมบ้าน

**สองคนเครื่องเดียว · ตะกร้อลอดห่วง**
- คีย์บอร์ด: ตัวชมพูเดินด้วย `A` `D` กระโดดด้วย `W` เตะด้วย `Space` · ตัวมิ้นต์เดินด้วย `←` `→` กระโดดด้วย `↑` เตะด้วย `Enter`
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊กไว้เดิน กับปุ่ม **กระโดด** และ **เตะ** โยกจอยไปหาเพื่อนตอนกดเตะคือส่ง

**สองคนเครื่องเดียว · ดนตรีจังหวะคู่**
- คีย์บอร์ด: ตัวชมพูตีกลองด้วย `A` (เสียงต่ำ) กับ `D` (เสียงสูง) · ตัวมิ้นต์ตีระนาดด้วย `←` กับ `→` · `Esc` พักเพลง เล่นต่อแล้วเพลงจะย้อนให้ตั้งตัวครึ่งห้อง
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีปุ่มกลม **ต่ำ** กับ **สูง**

**สองคนเครื่องเดียว · ต่อตึกด้วยกัน**
- คีย์บอร์ด: ตัวชมพูกด `W` หรือ `Space` ตัวมิ้นต์กด `↑` หรือ `Enter` เพื่อปล่อยครึ่งตึก · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีปุ่ม **ปล่อย** ปุ่มใหญ่ปุ่มเดียว

**สองคนเครื่องเดียว · วิ่งสามขา**
- คีย์บอร์ด: ตัวชมพูใช้ `D` ขาใน `A` ขานอก · ตัวมิ้นต์ใช้ `←` ขาใน `→` ขานอก · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีปุ่มกลม **ขาใน** กับ **ขานอก**

**สองคนเครื่องเดียว · เรือยาวพายคู่**
- คีย์บอร์ด: ตัวชมพูพายฝั่งซ้ายด้วย `W` ทวนด้วย `S` · ตัวมิ้นต์พายฝั่งขวาด้วย `↑` ทวนด้วย `↓` · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: ฝั่งซ้ายของจอพายซ้าย ฝั่งขวาพายขวา แต่ละฝั่งมีปุ่ม **พาย** กับ **ทวน**

**สองคนเครื่องเดียว · ชักว่าวคู่**
- คีย์บอร์ด: ใครเป็นคนวิ่งใช้ซ้ายขวาของตัวเอง (ชมพู `A` `D` มิ้นต์ `←` `→`) ใครคุมสายใช้ขึ้นลงของตัวเอง (ชมพู `W` `S` มิ้นต์ `↑` `↓`) ขึ้นคือดึงสาย ลงคือผ่อนสาย ปุ่มพิเศษ (ชมพู `Space` มิ้นต์ `Enter`) คือวิ่งเร็วหรือกระตุก · `Esc` พักเกมและสลับหน้าที่
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊กกับปุ่มพิเศษ คนวิ่งโยกซ้ายขวา คนคุมสายดันขึ้นเพื่อดึง ดึงลงเพื่อผ่อน

**สองคนเครื่องเดียว · ย้ายบ้านแบกของ**
- คีย์บอร์ด: ตัวชมพูเดินด้วย `W` `A` `S` `D` ยก/วางด้วย `Space` · ตัวมิ้นต์เดินด้วยปุ่มลูกศร ยก/วางด้วย `Enter` · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊กกับปุ่ม **ยก/วาง**

**สองคนเครื่องเดียว · แอบจุ๊บในโรงหนัง**
- คีย์บอร์ด: ตัวชมพูกด `D` ค้างไว้เพื่อเอียงเข้าหา `A` ยกป๊อปคอร์น · ตัวมิ้นต์กด `←` ค้างไว้เพื่อเอียงเข้าหา `→` ยกป๊อปคอร์น · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีปุ่มกลมสองปุ่ม ปุ่มด้านใน (ขอบสองชั้น) คือเอียงหา ปุ่มด้านนอกคือป๊อปคอร์น

**สองคนเครื่องเดียว · เดทแรกห้ามตด**
- แต่ละคนมีปุ่มด้านใน (ชมพู `D` มิ้นต์ `←`) กับปุ่มด้านนอก (ชมพู `A` มิ้นต์ `→`) คนท้องปั่นป่วนกดค้างปุ่มด้านในเพื่อเกร็ง กดปุ่มด้านนอกเพื่อปล่อย คนช่วยกลบกดปุ่มด้านนอกเพื่อไอ ปุ่มด้านในเพื่อลากเก้าอี้ · `Esc` พักเกมและสลับหน้าที่
- มือถือหรือแท็บเล็ต: ปุ่มกลมสองปุ่มต่อฝั่ง เขียนบอกไว้ว่าปุ่มไหนทำอะไร

**สองคนเครื่องเดียว · แย่งผ้าห่ม**
- คีย์บอร์ด: ตัวชมพูขยับด้วย `A` `D` ดึงผ้าห่มด้วย `Shift` ซ้าย (กดค้าง) ตบยุงหรือสะบัดผ้าด้วย `Space` · ตัวมิ้นต์ขยับด้วย `←` `→` ดึงผ้าด้วย `Shift` ขวา ตบด้วย `Enter` · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊ก (โยกซ้ายขวา) ปุ่ม **ดึงผ้า** (กดค้าง) และปุ่ม **ตบ สะบัด**

**สองคนเครื่องเดียว · ปีนหน้าต่างหาแฟน**
- คีย์บอร์ด: คนปีนเดินด้วยซ้ายขวาของตัวเอง (ชมพู `A` `D` มิ้นต์ `←` `→`) ดันขึ้นเพื่อจับผ้าแล้วปีน ดันลงเพื่อปีนลง ปุ่มพิเศษคือซ่อนในพุ่มไม้หรือออกจากพุ่ม · คนบนห้องดันลง (ชมพู `S` มิ้นต์ `↓`) เพื่อหย่อนผ้า ดันขึ้นเพื่อเก็บผ้าหรือช่วยดึงคนปีน ปุ่มพิเศษคือขึ้นเตียงหรือกลับมาที่หน้าต่าง · ปุ่มพิเศษ ชมพู `Space` มิ้นต์ `Enter` · `Esc` พักเกมและสลับหน้าที่
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊กกับปุ่มพิเศษ

**สองคนเครื่องเดียว · ฝ่าดงกับดัก**
- คีย์บอร์ด: ตัวชมพูเดินด้วย `W` `A` `S` `D` ดึงคันโยกด้วย `Space` · ตัวมิ้นต์เดินด้วยลูกศร ดึงคันโยกด้วย `Enter` · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊ก (เดินได้ทุกทาง) กับปุ่ม **ดึงคันโยก**

**สองคนเครื่องเดียว · ติดเกาะกับแฟน**
- คีย์บอร์ด: ตัวชมพูเดินด้วย `W` `A` `S` `D` หยิบ/ทำด้วย `Space` · ตัวมิ้นต์เดินด้วยลูกศร หยิบ/ทำด้วย `Enter` · `Esc` พักเกม
- มือถือหรือแท็บเล็ต: แต่ละฝั่งมีจอยสติ๊ก (เดินได้ทุกทาง) กับปุ่ม **หยิบ/ทำ**

**ออนไลน์คนละเครื่อง**
1. ทั้งสองคนเปิดหน้าเกมในมือถือตัวเอง แล้วกด **เล่นออนไลน์ คนละเครื่อง**
2. คนหนึ่งกด **เปิดห้อง** จะได้รหัส 4 ตัวเลข คนนี้เป็นตัวชมพูและเป็นคนเลือกด่าน
3. อีกคนกด **เข้าห้องของแฟน** แล้วใส่รหัส คนนี้เป็นตัวมิ้นต์
4. เลือกด่านผจญภัย ร้านในครัววุ่นวาย คืนในป้องกันบ้าน เส้นทางในขับรถคู่ สนามตะกร้อ เพลงในดนตรีจังหวะคู่ ไซต์ในต่อตึกด้วยกัน สนามวิ่งสามขา สายน้ำในเรือยาว บ้านที่รับย้าย ลานว่าว รอบหนัง มื้ออาหาร คืนในแย่งผ้าห่ม ภารกิจปีนหน้าต่าง เส้นทางฝ่าดงกับดัก หรือเกาะในติดเกาะกับแฟน ฉากจะเปิดพร้อมกันทั้งสองเครื่อง แต่ละเครื่องมีปุ่มของตัวเองชุดเดียว

ถ้าใครพลาด จะเริ่มด่านใหม่พร้อมกันทั้งคู่ ความคืบหน้าและหัวใจที่เก็บได้จะจำไว้ในเบราว์เซอร์ของแต่ละเครื่อง

**เต็มจอ**
- กดปุ่มเต็มจอที่แถบบนหรือหน้าแรก หรือกด `F` บนคีย์บอร์ด บน Android จะล็อกจอเป็นแนวนอนให้ด้วย
- iPhone ไม่ให้เว็บเปิดเต็มจอเอง ให้เปิดเกมใน Safari กดปุ่ม **แชร์** แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** เปิดจากไอคอนนั้นจะเต็มจอเหมือนแอป ความคืบหน้าในไอคอนนี้แยกจากใน Safari

## เอาขึ้น GitHub Pages

**แบบไม่ต้องใช้คำสั่ง (ผ่านเว็บ GitHub)**
1. สร้าง repository ใหม่ใน GitHub ถ้าใช้ GitHub แบบฟรี ต้องตั้งเป็น **Public** ถึงจะเปิด Pages ได้
2. ในหน้า repo กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ลงไป (`index.html`, `manifest.webmanifest`, `js/`, `icons/`, `tests/`, `README.md`, `package.json`) จากนั้นกด **Commit changes**
3. ไปที่ **Settings → Pages** ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch** เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณหนึ่งนาที เกมจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

**แบบใช้ git**
```bash
git init
git add .
git commit -m "ทางสองเรา"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/ชื่อrepo.git
git push -u origin main
```
แล้วเปิด Pages ตามข้อ 3 ด้านบน

## โหมดออนไลน์ทำงานยังไง

ใช้ [PeerJS](https://peerjs.com/) ช่วยจับคู่สองเครื่องผ่านรหัสห้อง จากนั้นข้อมูลเกมวิ่งตรงระหว่างสองเครื่อง ไม่ต้องมีเซิร์ฟเวอร์ของตัวเองและไม่ต้องสมัครบัญชีอะไร

- เครื่องของคนเปิดห้อง (ตัวชมพู) เป็นตัวคำนวณฉาก กล่อง ประตู และแผ่นกด อีกเครื่องส่งการเคลื่อนไหวของตัวมิ้นต์มาให้
- ในดนตรีจังหวะคู่ แต่ละเครื่องเล่นเพลงและตัดสินจังหวะของคนถือเครื่องเอง แล้วส่งผลแต่ละโน้ตให้กัน เครื่องคนเปิดห้องเป็นคนรวมแต้ม คอมโบ และพลังวง ส่วนเสียงของอีกคนจะเล่นตามโน้ตในเครื่องเรา เน็ตหน่วงจึงไม่ทำให้ตีไม่ตรง
- สองเครื่องเทียบนาฬิกากันตลอดเวลาที่เล่น (วัดเวลาไปกลับของข้อความแล้วเก็บค่าที่ไวที่สุด) จึงรู้ว่าอีกเครื่องกดปุ่มตอนไหนจริงๆ
- ในวิ่งสามขา ทุกครั้งที่กดจะส่งเวลาที่กดในเครื่องตัวเองไป เครื่องคนเปิดห้องจับคู่ก้าวตามลำดับและตัดสินจากเวลาจริงที่กด และรอขาของอีกคนที่ยังเดินทางมาตามความหน่วงของเน็ต เน็ตหน่วงจึงไม่ทำให้ก้าวผิดจังหวะหรือโยกเยก
- ในเรือยาวพายคู่ เครื่องคนเปิดห้องเป็นคนคุมเรือ น้ำ หิน และเรือคันอื่น การพายของอีกคนส่งไปพร้อมเวลาที่กด ระหว่างรอ เรือในจออีกเครื่องไหลต่อไปเองแล้วค่อยๆ เข้าที่
- ในชักว่าวคู่ เครื่องคนเปิดห้องเป็นคนคุมว่าว ลม และว่าวคนอื่น อีกเครื่องส่งจอยกับปุ่มของหน้าที่ตัวเองไป และขยับครึ่งที่ตัวเองคุมในจอตัวเองทันที (ลมคิดจากตัวเลขเดียวกันทั้งสองเครื่อง) แล้วค่อยๆ เข้าที่ตามเครื่องคนเปิดห้อง คนเปิดห้องเป็นคนกดสลับหน้าที่
- ในแอบจุ๊บในโรงหนัง แต่ละเครื่องเอียงตัวคนถือเครื่องเองทันทีแล้วส่งว่าเอียงไปแค่ไหน เครื่องคนเปิดห้องเป็นคนนับแต้ม ตัดสินว่าใครหันมาเห็น และนับป๊อปคอร์น (คนรอบๆ หันมาตามตัวเลขเดียวกันทั้งสองเครื่อง)
- ในเดทแรกห้ามตด ทุกครั้งที่กด (ปล่อย ไอ ลากเก้าอี้) จะส่งเวลาที่กดไปด้วย (ใช้นาฬิกาที่เทียบกันแล้ว) เครื่องคนเปิดห้องรอแป๊บหนึ่งก่อนตัดสินว่ามีใครได้ยิน เสียงที่ไปช้าเพราะเน็ตจึงยังกลบทัน
- ในแย่งผ้าห่ม เครื่องคนเปิดห้องเป็นคนคุมความอุ่น ยุง และเรื่องกลางดึก อีกเครื่องขยับตัวเองกับดึงผ้าในจอตัวเองทันที แล้วค่อยๆ เข้าที่ตามเครื่องคนเปิดห้อง
- ในปีนหน้าต่างหาแฟน อีกเครื่องเดินหรือปีน (หรือหย่อนผ้า ขึ้นเตียง) ในจอตัวเองทันทีแล้วส่งว่าอยู่ตรงไหน เครื่องคนเปิดห้องเชื่อถ้าเป็นไปได้ เป็นคนตัดสินว่าใครโดนเห็น หมาเห่า และพ่อเปิดประตู ถ้าเครื่องคนเปิดห้องทำให้ร่วงหรือเข้าห้องได้แล้ว อีกเครื่องจะตามทันที คนเปิดห้องเป็นคนกดสลับหน้าที่
- ในฝ่าดงกับดัก อีกเครื่องเดินตัวมิ้นต์ในจอตัวเองทันทีและตัดสินเองว่าตัวเองโดนกับดักไหม (กับดักเดินตามจังหวะเดียวกันทั้งสองเครื่อง) แล้วส่งตำแหน่งกับการล้มไป เครื่องคนเปิดห้องเชื่อถ้าเป็นไปได้ เป็นคนคุมแผ่นหิน ประตู คันโยก เพชร หัวใจ จุดเซฟ และการช่วยพยุง ถ้าเครื่องคนเปิดห้องพยุงให้ลุกหรือส่งกลับจุดเซฟ อีกเครื่องจะตามทันที
- ในติดเกาะกับแฟน อีกเครื่องเดินตัวเองในจอตัวเองทันทีแล้วส่งตำแหน่งกับการกดปุ่มไป เครื่องคนเปิดห้องคุมทุกอย่างบนเกาะ ทั้งแถบของสองคน ไฟ ของที่วางไว้ สัตว์ เรือ และความรัก ถ้าเครื่องคนเปิดห้องให้เริ่มวันใหม่ อีกเครื่องจะตามทันที
- ในย้ายบ้านแบกของ อีกเครื่องเดินตัวมิ้นต์เองทันทีและส่งตำแหน่งไป ตอนยกของใหญ่ด้วยกัน เครื่องคนเปิดห้องเป็นคนขยับของ ส่วนปุ่มยก/วางส่งเป็นจำนวนครั้งที่กด กดแล้วไม่หาย
- ในต่อตึกด้วยกัน แต่ละเครื่องแกว่งปั้นจั่นของคนถือเครื่องเอง พอกดปล่อยจะส่งตำแหน่งกับเวลาที่ปล่อยไป เครื่องคนเปิดห้องเป็นคนตัดสินว่าลงตรงไหน โดยดูตึกโยกตามเวลาในเครื่องคนที่ปล่อย ครึ่งตึกจึงลงตรงที่เห็นในจอตัวเอง
- ในตะกร้อลอดห่วง เครื่องคนเปิดห้องเป็นคนคุมลูก อีกเครื่องเดินตัวมิ้นต์เองแล้วส่งจังหวะเตะมา เครื่องคนเปิดห้องจะย้อนดูว่าตอนนั้นลูกอยู่ตรงไหนในจอของอีกคน แล้วเตะจากจุดนั้น เน็ตหน่วงนิดหน่อยลูกก็ยังโดนเท้า
- ในขับรถคู่ เครื่องคนเปิดห้องเป็นคนคุมรถ รถคันอื่น ไก่ และรถไฟ อีกเครื่องส่งครึ่งของการควบคุมที่ตัวเองถือมา และขยับรถในจอตัวเองไปก่อนเพื่อให้รู้สึกไม่หน่วง คนเปิดห้องเป็นคนกดสลับหน้าที่
- ในป้องกันบ้าน เครื่องคนเปิดห้องเป็นคนคุมผี กระสุน เหรียญ และตะเกียง อีกเครื่องส่งการเดิน ท่าพิเศษ และการกดใช้มา
- ในครัววุ่นวาย เครื่องคนเปิดห้องเป็นคนนับเวลา ออเดอร์ เตา และไฟ อีกเครื่องส่งการเดินกับการกดหยิบ/วางมา ของที่ตัวมิ้นต์หยิบจะขึ้นมือหลังกดเสี้ยววินาทีตามความเร็วเน็ต
- ถ้าเน็ตช้า คนเล่นตัวมิ้นต์จะรู้สึกว่าการเข็นกล่องหน่วงนิดหน่อย
- เครือข่ายบางแห่ง เช่น Wi-Fi บริษัทหรือโรงเรียน อาจกันการเชื่อมต่อแบบนี้ ถ้าต่อไม่ติดให้ลองสลับไปใช้เน็ตมือถือ
- เซิร์ฟเวอร์จับคู่ฟรีของ PeerJS เป็นบริการสาธารณะ ถ้าวันไหนล่ม โหมดออนไลน์จะเข้าห้องไม่ได้ชั่วคราว ส่วนโหมดเครื่องเดียวเล่นได้ตามปกติ

แผนที่ด่านเขียนเป็นตัวอักษร 30×17 ช่องใน `js/levels.js` เช่น `#` พื้นหิน, `P` `M` จุดเกิด, `@` ประตูหัวใจ, `1`–`6` แผ่นกด, `A`–`F` ประตูที่เปิดเมื่อแผ่นเลขเดียวกันทำงาน, `a`–`f` แท่งแสงที่โผล่เมื่อแผ่นทำงาน, `G`–`L` แผ่นหนัก, `u`–`z` สวิตช์โยก, `p` `m` แสงสีชมพูและมิ้นต์, `o` ลังไม้, `O` หิน, `^` หนาม, `~` น้ำ, `*` หัวใจ, `-` คานไม้ที่กระโดดทะลุขึ้นได้, `q` ระฆังเงา, `X` หินสลับร่าง, `r` พื้นผุ

แต่ละด่านตั้งค่าเพิ่มได้ เช่น `thread: 4` ผูกด้ายแดงยาว ๔ ช่อง, `echo: 4` ให้ระฆังจำ ๔ วินาที, `dark: true` ทำให้ด่านมืด, `lifts: [...]` ใส่ใบบัวลิฟต์

ของในบทที่ ๔ ตั้งเป็นรายการในแต่ละด่าน
- `fans: [{ x, y, h, w, ids }]` พัดลมที่ช่อง (x, y) เป่าสูง `h` ช่อง กว้าง `w` ช่อง ถ้าใส่ `ids` จะทำงานเฉพาะตอนแผ่นหรือสวิตช์เลขนั้นทำงาน
- `seesaws: [{ x, y, w, tilt }]` กระดานหกกว้าง `w` ช่อง ตั้งบนพื้นแถว `y` `tilt: -1` ให้ฝั่งซ้ายต่ำตอนเริ่ม `1` ให้ฝั่งขวาต่ำ
- `portals: [{ a: [x, y], b: [x, y], id }]` ประตูมิติคู่หนึ่ง ถ้าใส่ `id` จะเปิดเมื่อแผ่นหรือสวิตช์เลขนั้นทำงาน
- `crumbleBack: 3.5` วินาทีก่อนพื้นผุจะกลับมา

แผนที่ขับรถคู่เขียนเป็นตัวอักษร 32×18 ช่องใน `js/rlevels.js` เช่น `.` ถนน, ` ` (เว้นวรรค) หญ้า ขับได้แต่ช้า, `#` ตึก, `t` ต้นไม้, `=` ทางรถไฟ, `p` แอ่งน้ำ, `k` ลานไก่, `S` จุดออกรถ, `A`–`F` ร้าน, `a`–`f` บ้านลูกค้า ชื่อร้านกับบ้านตั้งใน `shops` และ `houses` เส้นทางรถคันอื่นตั้งใน `traffic` และรถไฟตั้งใน `trains`

## ทดสอบ

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm test
```

- `tests/lint.js` ตรวจแผนที่ผจญภัยทุกด่าน เช่น ขนาดแผนที่ แผ่นกดทุกแผ่นมีของให้เปิด จุดเกิดและประตูไม่ลอยหรือจมกำแพง หัวใจไม่ถูกฝังในหิน
- `tests/test.js` เช็กฟิสิกส์พื้นฐานและด่านบทที่ ๑ เช่น กระโดดคนเดียวขึ้นได้ 2 ช่อง เหยียบหัวกันขึ้นได้ 3 ช่อง
- `tests/bot.js` `tests/bot3.js` และ `tests/bot4.js` ให้บอทเล่นตามเฉลยของบทที่ ๒ ๓ และ ๔ ทุกด่านจนเข้าประตูได้จริง
- `tests/cheese.js` `tests/cheese3.js` และ `tests/cheese4.js` เช็กว่าทางลัดที่ไม่ควรได้ผลใช้ไม่ได้จริง เช่น คนเดียวดีดตัวเองด้วยกระดานหกไม่ได้ และพัดลมไม่ทำงานถ้าไม่มีใครยืนกดแผ่น
- `tests/nettest.js` จำลองสองเครื่องต่อกันผ่านเน็ตที่หน่วง แล้วเล่นบทที่ ๒ ๓ และ ๔ ให้จบ ปรับความหน่วงได้ด้วย `node tests/nettest.js --ms=200`
- `tests/fuzz.js` ให้สองคนกดปุ่มมั่วๆ ในทุกด่านผจญภัยหลายรอบ แล้วเช็กว่าไม่มีใครหรือลังติดอยู่ในกำแพง หลุดออกนอกแผนที่ หรือค่าพัง ปรับเวลาและจำนวนรอบได้ด้วย `node tests/fuzz.js 60 40`

- `tests/mbot.js` ให้นักดนตรีบอทเล่นทุกเพลง ตีแม่นต้องได้สามดาว ตีหลวมได้น้อยลง เล่นคนเดียวหรือกดรัวมั่วๆ ต้องไม่ผ่าน
- `tests/wtest.js` เช็กกติกาต่อตึก เช่น ตัดส่วนที่ยื่น เป๊ะแล้วงอกเข้าหาเพื่อน รอยต่อห่างแล้วตึกโยก หมวกนิรภัย ปั้นจั่นปล่อยเอง ลมพัด ตึกโยก เจดีย์สอบ และต่อตึกสองเครื่องผ่านเน็ตที่หน่วงจนได้ตึกเดียวกัน
- `tests/wbot.js` ให้ช่างบอทหลายฝีมือต่อทุกไซต์ คนแม่นต้องถึงยอด คนเล่นหลวมได้ดาวน้อยลงในไซต์หลังๆ กดมั่วหรือเพื่อนไม่ยอมกดต้องไม่ได้ดาว
- `tests/ltest.js` เช็กกติกาวิ่งสามขา เช่น ก้าวเป๊ะก้าวยาวกว่า กดผิดขาหรือคนละขาเสียหลัก รีบกดเร็วเกินสะดุด รั้ว โคลน พื้นเปียก กดหลังเข้าเส้นชัยไม่มีผล และสองเครื่องที่หน่วง ๘๐ ถึง ๒๕๐ มิลลิวินาทียังวิ่งได้เท่าเล่นเครื่องเดียว
- `tests/lbot.js` ให้นักวิ่งบอทหลายฝีมือลงทุกสนาม คนแม่นต้องได้สามดาว มือใหม่ต้องได้ดาวในสนามแรกๆ คนเดียว กดรัว หรือรีบเกินต้องไม่ได้ดาว
- `tests/btest.js` เช็กกติกาเรือยาว เช่น พายข้างเดียวเลี้ยว พายพร้อมกันไปตรงและไกลกว่า พายซ้ำก่อนจบจังหวะไม่มีผล ทวนน้ำเบรก ชนหินแรงๆ เรือร้าวจนล่ม กระทง แก่ง วังน้ำวน และพายสองเครื่องผ่านเน็ตที่หน่วงจนเห็นเรือตรงกัน
- `tests/bbot.js` ให้ฝีพายบอทหลายฝีมือ (มีเวลาตอบสนองและการกะระยะแบบคน) พายทุกสายน้ำ คนแม่นต้องได้สามดาว คนพายหลวมไม่ได้สามดาว พายคนเดียวเรือวนอยู่กับที่ และพายมั่วไม่ได้ดาว
- `tests/vtest.js` เช็กกติกาย้ายบ้าน เช่น ถือปลายเดียวยกไม่ขึ้น เดินทางเดียวกันของไปตรง เดินสวนกันของหมุน ของไม่ทะลุกำแพง วางตรงเส้นประ ศาลพระภูมิหันผิดวางไม่ลง ชนแรงบุบ ไถลเบาๆ ไม่บุบ ฝน ทิป ทุกบ้านไม่มีทางไหนถูกปิดตาย และย้ายบ้านสองเครื่องผ่านเน็ตที่หน่วงโดยตัวมิ้นต์ไม่โดนดึงกลับ
- `tests/vbot.js` ให้ทีมขนของบอท (หาทางยกของผ่านประตูด้วย A*) ย้ายทุกบ้าน ทีมที่ระวังต้องได้สามดาว ทีมที่ชนไปเรื่อยได้ดาวน้อยลง คนเดียวหรือกดมั่วต้องไม่ได้ดาว ส่วนบอทอยู่ใน `tests/vcrew.js`
- `tests/itest.js` เช็กกติกาชักว่าว เช่น ยืนเฉยๆ ว่าวขึ้นไม่ได้ วิ่งสวนลมพร้อมผ่อนสายส่งว่าวขึ้น ผ่อนสายตอนลมดีว่าวสูงขึ้น ดึงสายสายตึงขึ้น ลมกระโชกกับสายที่ถือไว้แน่นทำให้สายขาดแต่ผ่อนสายแล้วรอด สายหมดม้วนผ่อนไม่ได้ ลมหยุดว่าวตก ต้นไม้ สายไฟ สายคนอื่นเสียดจนขาด แต้ม ลมเหมือนกันทุกเครื่อง และชักว่าวสองเครื่องผ่านเน็ตที่หน่วง
- `tests/ibot.js` ให้ทีมชักว่าวบอทหลายฝีมือลงทุกลาน (มีเวลาตอบสนองแบบคน) ทีมเก่งได้สองถึงสามดาว ทีมมือใหม่ได้ดาวในลานแรกๆ ทีมที่ช้าไม่ได้สามดาวในลานที่มีลมกระโชก วิ่งคนเดียว คุมสายคนเดียว กดมั่ว หรือยืนเฉยๆ ต้องไม่ได้ดาว ส่วนบอทอยู่ใน `tests/icrew.js`
- `tests/ctest.js` เช็กกติกาโรงหนัง เช่น เอียงคนเดียวไม่จุ๊บ จุ๊บนานแต้มคูณ คนหันมามีสัญญาณก่อน โดนเห็นแล้วหน้าแดงเอียงไม่ได้ ป๊อปคอร์นบังฝั่งตัวเอง ฉากเสียงดังไม่มีใครหัน กอดตอนผีออก และสองเครื่องผ่านเน็ตที่หน่วง
- `tests/cbot.js` ให้คู่รักบอทหลายฝีมือดูทุกรอบ (มีเวลาตอบสนองแบบคน) คู่ที่ระวังได้สามดาว คู่ที่ช้าไม่ได้สามดาว เอียงคนเดียว เอียงค้าง หรือกดมั่วไม่ได้ดาว ส่วนบอทอยู่ใน `tests/ccrew.js`
- `tests/ftest.js` เช็กกติกาห้ามตด เช่น แก๊สขึ้น เกร็งแล้วขึ้นช้าแต่หน้าแดง ปล่อยแล้วเสียงดังตามมา ไอหรือลากเก้าอี้ให้ตรงจังหวะถึงจะกลบได้ เสียงในร้านกลบได้ ไอเปล่าๆ ดูแปลก พัดลมพากลิ่น และกดผ่านเน็ตที่หน่วงก็ยังกลบทัน
- `tests/fbot.js` ให้คู่บอทหลายฝีมือกินทุกมื้อ คู่ที่ประสานกันดีได้สามดาว ปล่อยคนเดียวไม่มีใครกลบหรือกลั้นไว้ทั้งมื้อไม่ได้ดาว ส่วนบอทอยู่ใน `tests/fcrew.js`
- `tests/htest.js` เช็กกติกาแย่งผ้าห่ม เช่น ห่มแล้วอุ่น หลุดแล้วหนาวจนตื่น นอนชิดอุ่นกว่า ดึงพร้อมกันคือแย่ง ตัวไหลจนตกเตียง ดิ้น กลิ้ง ตด ยุง และสองเครื่องผ่านเน็ตที่หน่วง
- `tests/hbot.js` ให้คู่บอทหลายฝีมือนอนทุกคืน คู่ที่คอยดูแลกันได้สามดาว คู่ที่ขี้เกียจได้น้อยลง นอนเฉยๆ ดูแลคนเดียว หรือดิ้นมั่วไม่ได้ดาว ส่วนบอทอยู่ใน `tests/hcrew.js`
- `tests/ntest.js` เช็กกติกาปีนหน้าต่าง เช่น ยืนนิ่งในที่สว่างไม่โดนเห็นแต่ขยับโดน แสงเรืองก่อนไฟเปิด ไฟรถเห็นผ้าที่ห้อยอยู่ ทางกรวดปลุกหมา ซ่อนในพุ่มไม้ จับผ้า ปีน ช่วยดึง ขึ้นเตียงแล้วผ้าไหล ร่วง พ่อเปิดประตู ฟ้าสาง และสองเครื่องผ่านเน็ตที่หน่วงทั้งตอนอีกเครื่องปีนและตอนอีกเครื่องอยู่บนห้อง
- `tests/nbot.js` ให้คู่บอทหลายฝีมือ (เห็นแค่สิ่งที่คนเห็นและได้ยิน ช้าแบบคน) ทำทุกภารกิจ คู่ที่ระวังได้สามดาว คู่ทั่วไปส่วนใหญ่ได้ดาว คู่ที่สะเพร่าไม่ค่อยได้สามดาว ปีนคนเดียว รอบนห้องคนเดียว วิ่งเข้าไปตรงๆ หรือกดมั่วไม่ได้ดาว ส่วนบอทอยู่ใน `tests/ncrew.js`
- `tests/ptest.js` เช็กกติกาฝ่าดงกับดัก เช่น เดินชนกำแพง สองคนห่างกันเกินจอไม่ได้ ตกน้ำ หนามโผล่ปลายก่อนขึ้น แผ่นหินหยุดหนาม ประตูไม่ปิดทับคน คันโยกคู่ต้องดึงพร้อมกัน ลูกธนูหยุดที่กำแพง ท่อนไม้ หินกลิ้ง คานไฟ ใบเลื่อย ช่วยพยุง เสียหัวใจ จุดเซฟ เพชร ประตูวิหาร หมดเวลา ทุกเส้นทางเดินถึงวิหารได้ และสองเครื่องผ่านเน็ตที่หน่วง
- `tests/pbot.js` ให้คู่บอทหลายฝีมือ (มองไปข้างหน้าได้แป๊บเดียว ออกตัวช้า และใจร้อนบ้างแบบคน) เดินทุกเส้นทาง คู่ที่ระวังได้สามดาว คู่ทั่วไปส่วนใหญ่ได้ดาว คู่ที่สะเพร่าไม่ค่อยได้สามดาว เดินคนเดียว ยืนเฉยๆ วิ่งตรงไปเลย หรือเดินมั่วไม่ได้ดาว ส่วนบอทอยู่ใน `tests/pcrew.js`
- `tests/stest.js` เช็กกติกาติดเกาะกับแฟน เช่น เขย่ามะพร้าวสามทีถึงหล่น รับทันหรือโดนหัว ดื่มน้ำทะเลแล้วเค็ม ถูไม้ต้องสลับคน ย่างปลา ไฟมอดในฝน งอนแล้วง้อ ปูหนีบ ลิงขโมยแล้วไล่จับ น้ำขึ้นพาของไป หมดแรงแล้วช่วยฟื้น เริ่มวันใหม่ SOS กับเรือ ทุกเกาะมีทางรอด และสองเครื่องผ่านเน็ต
- `tests/sbot.js` ให้คู่บอทหลายฝีมือ (คิดช้าเร็ว สังเกตช้า พลาดบ่อย ใส่ใจแฟนมากน้อย) อยู่บนทุกเกาะสามวัน คู่ที่ระวังรอดทุกครั้งและส่วนใหญ่ได้สามดาว คู่ที่สะเพร่าได้สามดาวน้อยกว่า อยู่คนเดียว ยืนเฉยๆ หรือเดินมั่วไม่รอด ส่วนบอทอยู่ใน `tests/screw.js`
- `tests/tfuzz.js` กดมั่วๆ ในทุกร้าน ทุกคืน ทุกเส้นทาง ทุกสนามตะกร้อ ทุกเพลง ทุกไซต์ ทุกสนามวิ่ง ทุกสายน้ำ ทุกบ้าน และทุกลานว่าว แล้วเช็กว่าไม่มีใครเดินทะลุโต๊ะหรือกำแพง ของไม่ซ้ำสองที่ รถไม่จมตึกหรือติดตายจนถอยไม่ได้ ตึกไม่ซ้อนกัน เรือไม่ขึ้นตลิ่ง เฟอร์นิเจอร์ไม่จมผนัง ข้อความแปลกๆ จากอีกเครื่องไม่ทำให้พัง และทุกรอบจบได้
- `tests/dbot.js` ให้ฮีโร่บอทสองตัวเฝ้าบ้านทุกคืนจนได้สามดาว แล้วลองให้เล่นคนเดียวกับยืนเฉยๆ เพื่อเช็กว่าคืนหลังๆ ต้องช่วยกันจริง

ถ้าแก้แผนที่ด่าน แผนผังร้าน คลื่นผี แผนที่เมือง เพลง ไซต์ก่อสร้าง สนามวิ่ง สายน้ำ บ้าน ลานว่าว เส้นทางฝ่าดงกับดัก หรือเกาะติดเกาะ ให้รัน `npm test` ทุกครั้ง เพื่อเช็กว่ายังผ่านได้และไม่มีทางลัด
